                        🛡️ Respuestas Rápidas para Frank ante Preguntas Críticas del Prof. Zamata
                    

                    

                        

                            1. ¿Saturación de red por sondeo cada 30s? → "No hay saturación: usamos peticiones HEAD ultralivianas de Spring Boot Actuator (/actuator/health) de pocos bytes en hilos asíncronos desacoplados del tráfico principal."
                        

                        

                            2. ¿Por qué SHA-256 y no MD5 o CRC32? → "MD5 tiene colisiones conocidas y CRC32 no es criptográfico. SBS y BCRP exigen SHA-2 de 256 bits para validez legal, resistencia a preimagen y no repudio."
                        

                        

                            3. ¿Qué pasa si PostgreSQL o el backend se caen? → "Arquitectura con Graceful Degradation: la consola detecta el fallo del canal REST y conmuta automáticamente al motor local reactivo con Web Crypto API sin pantallas en blanco."
                        

                        

                            4. ¿Problema del antipatrón N+1 en JPA? → "Resuelto mediante JPQL con cláusula JOIN FETCH sobre las entidades relacionadas, recuperando todo en un único round-trip a PostgreSQL."
